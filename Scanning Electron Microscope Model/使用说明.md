# 导管腔识别与标定 — 使用说明

看扫描电镜（SEM）图，自动找出导管腔（黑窟窿），标出来，再算出指标、导出 Excel。

日常就四步：**机器先标 → 人改对 → 出表 →（可选）再训练，让下一批更准**。

---

## 一张图长什么样？

输出是左右对照图：

| 左边 | 右边 |
|------|------|
| 原图（给你改） | 程序标好的结果 |

右边颜色含义：

| 颜色 | 含义 |
|------|------|
| 绿圈 | 导管腔 |
| 橙框 | 双导管区域 |
| 紫十字 | 腔的大小（Ai） |
| 蓝线 | 壁厚（TVW） |

结果一般在：

- `output/复核_1-40/`、`output/复核_41-63/` — 对照图  
- `output/人工标定/` — 人工修订样例  
- `output/excel_samples/` — Excel 表  

---

## 日常怎么用

先进入目录：

```bash
cd vessel_pipeline
```

### 1. 自动识别一批样品

例如处理样品 41～63：

```bash
python run_review_batch.py 41 63 --out-dir 复核_41-63 --wipe --hybrid
```

| 参数 | 含义 |
|------|------|
| `41 63` | 样品号从几到几 |
| `--out-dir` | 结果放到 `output/` 下哪个文件夹 |
| `--wipe` | 先清空再写，避免旧图混在一起 |
| `--hybrid` | 推荐：AI 找腔 + 规则配对/测量 |

结果在：`output/复核_41-63/`

### 2. 人眼检查、改错

打开对照图，看有没有标错、漏标、该不该算双导管、壁厚对不对。

改法两种都行：

- 直接改左侧原图；或  
- 画到 `output/人工标定/` 里：

| 文件夹 | 怎么画 |
|--------|--------|
| `人工标定/单导管/` | 红线圈单导管 |
| `人工标定/双导管+壁厚+框/` | 蓝框圈双导管区 + 红线圈腔 + 短蓝线标壁厚 |

改完后，让程序按你的改动更新右侧：

```bash
python _patch_singles_from_human.py
python _patch_dual_from_human.py
```

### 3. 导出 Excel

```bash
python run_excel_from_review.py --review 复核_41-63 --lo 41 --hi 63
```

表在：`output/excel_samples/样品41-63_扫描电镜指标_自动分析结果.xlsx`

### 4.（可选）用改好的图再训练

改得越多、训得越准。例如用 1–40 的复核图：

```bash
python export_from_review_pngs.py --review 复核_1-40 --wipe
python train_lumen_seg.py --epochs 20 --model output/models/lumen_yolov8seg/weights/best.pt
```

训完再跑下一批自动识别即可。

## 推荐闭环（照抄即可）

```bash
# 1) 自动预标
python run_review_batch.py 1 40 --out-dir 复核_1-40 --wipe --hybrid

# 2) 人工改完后回写
python _patch_singles_from_human.py
python _patch_dual_from_human.py

# 3) 出表
python run_excel_from_review.py --review 复核_1-40 --lo 1 --hi 40

# 4) 用复核图重训（可选）
python export_from_review_pngs.py --review 复核_1-40 --wipe
python train_lumen_seg.py --epochs 20 --model output/models/lumen_yolov8seg/weights/best.pt

# 5) 标定下一批
python run_review_batch.py 41 63 --out-dir 复核_41-63 --wipe --hybrid
python run_excel_from_review.py --review 复核_41-63 --lo 41 --hi 63
```

## 常用入口一览

| 步骤 | 命令 | 作用 |
|------|------|------|
| 自动识别 | `run_review_batch.py … --hybrid` | 生成对照图 |
| 人工回写 | `_patch_singles_from_human.py` / `_patch_dual_from_human.py` | 按人工红圈/框/线更新右侧 |
| 出表 | `run_excel_from_review.py` | 从复核图出 Excel |
| 微调模型 | `export_from_review_pngs.py` + `train_lumen_seg.py` | 用复核图训练，下一批更准 |

其余 `.py` 为内部模块，日常不用单独跑。环境依赖见 `requirements.txt`。

## 附录：程序内部在判什么（日常可跳过）

只需知道大致原则：

- **够黑、够大**的圆孔才算导管（太小、浅灰、带纹理的不算）  
- 两个挨得近的可以成**双导管**；中间若有小洞（共壁小腔），则拆成两个单导管  
- 小腔不能套在大腔里面  
- 规则写在 `output/learned_rules.json`（换图仍有效，不按文件名记坐标）

更细的阈值（面积下限、间距约 1.5 µm、Ai/TVW/CWR 算法等）由程序自动处理，人工标定以你画的红圈/蓝框/短线为准。
