# 三个区域自动标定逻辑

样品显微镜图按视野分成三个区域。文件名：`样品序号-图片号 放大倍数.jpg`（如 `12-1 2X.jpg`）。每个样品 9 张图：视野 1–3 第一区域，4–6 第二区域，7–9 第三区域。长度、面积由右下角标尺换成 µm / µm²。旧表把三视野平均写成数字；新表原始量分列，平均和相对量用 Excel 公式。

在项目根目录执行（已有 `.venv` 时把 `python` 换成 `.\.venv\Scripts\python.exe`）。

## 日常：改规则 → 重标 → 出 Excel

改完规则后，**先重标图，再出表**。日常用这一条就够（不重新训练）：

```bash
python run_all.py --no-train
```

| 产物 | 路径 |
|------|------|
| 重标图 | `自动标定/第一区域`、`自动标定/第二区域`、`自动标定/第三区域` |
| 旧结果表 | `结果呈现表_推理.xlsx`（原始长度/个数/面积 + Python 平均） |
| 新结果表 | `结果呈现表_新_推理.xlsx`（原始量 + Excel 公式派生量） |

只动一个区域时：

| 做什么 | 命令 | 写出 |
|--------|------|------|
| **一区重标** | `python run_region1.py --no-train` | `自动标定/第一区域` + `推理结果/region1_metrics.csv` + 同步新表 |
| **二区重标 + 写表** | `python run_region2.py` | `自动标定/第二区域` + 旧表 `结果呈现表.xlsx` + 同步新表 |
| **二区只写表**（不重标） | `python run_region2.py --excel-only` | 用已有 CSV 填旧表和新表 |
| **三区重标 + 打分** | `python run_region3.py --no-optimize-box` | `自动标定/第三区域` + `推理结果/形成层 评分_自动.xlsx` + 同步新表 |
| **三区只改分**（框不动） | `python run_region3.py --score-only` | 同上，几何不变 |
| **三区一起出总表** | `python run_all.py --no-train` | 旧表 `结果呈现表_推理.xlsx` + 新表 `结果呈现表_新_推理.xlsx` |
| **只填新表**（不重标） | `python -m calibration.excel_export_new` | 用已有 CSV / 评分表填新表 |

抽几张图试规则（文件名含空格，要加引号）：

```bash
python run_region1.py --no-train --from-name "1-1 2X.jpg" --to-name "3-3 4X.jpg"
python run_region2.py --from-name "1-4 10X.jpg" --to-name "3-6 10X.jpg"
```

试完再全量 `run_all.py --no-train` 出旧表和新表。

# 第一区域：整切面六点与四层长度

视图 **1 / 2 / 3**（2X / 4X）。在茎横截面上画 **两条直线、六个点**，量半径、木质部、韧皮部、树皮/皮层四段长度。

## 目标

| 项目 | 说明 |
|------|------|
| 输入 | `原图/第一区域/` |
| 输出图 | `自动标定/第一区域/`（六点编号线） |
| 指标 | 四段长度（µm），每样品 3 张取平均 |

```
点1 髓心 ──────── 点2 树皮外缘                    绿线 = 半径
点3 内环 ──橙── 点4 ──蓝── 点5 ──红── 点6 树皮外缘   层界线
```

| 点 | 名称 | 颜色 | 含义 |
|----|------|------|------|
| 1 | pith | 绿起点 | 髓心（茎盘中心附近） |
| 2 | green_end | 绿终点 | 沿半径射线接到树皮外缘 |
| 3 | seg_inner | 橙起点 | 髓–木质部内环，不是髓心 |
| 4 | xylem | 橙/蓝交界 | 木质部 / 韧皮部分界 |
| 5 | phloem | 蓝/红交界 | 韧皮部 / 皮层分界 |
| 6 | bark | 红终点 | 层界线接到树皮外缘 |

- **半径** = 点1 → 点2
- **木质部** = 点3 → 点4
- **韧皮部** = 点4 → 点5
- **树皮/皮层** = 点5 → 点6

## 几何约束

1. 绿线、层界线各是一条直线；层上 3–4–5–6 **共线**。
2. 点1 在髓心，点3 在内环，两点距离至少约 `0.10 × 茎半径`。
3. 两射线夹角 **16°–165°**，禁止几乎重合或 180° 对穿。
4. 点2、点6 沿各自方向射到茎外缘（白背景），不落在组织内部。
5. 只画线和编号点，不画图例色块。
6. **4–5–6 三倍**：蓝线 4→5（韧皮部）相对红线 5→6（树皮）不足三倍时，只改点 5。

### 4–5–6 三倍规则

画完层界线后，检查蓝段和红段：

```
点4 ──蓝 4→5── 点5 ──红 5→6── 点6
```

| 情况 | 动作 |
|------|------|
| `4→5 < 3 × 5→6` | **点4、点6不动**，把点5沿 4–6 直线挪到 **3:1** 处，使 `4→5 = 3 × 5→6` |
| `4→5 ≥ 3 × 5→6` | 点5 不改 |

点5 仍在 4–6 上。3:1 时点5 落在 4→6 的 **3/4** 处（蓝占 3/4，红占 1/4）。点1–4 与绿线一律不动。

## 标尺

右下角打印标尺 → 像素长度 → 按倍率换成 µm。检不到标尺则该张不写长度。

| 倍率 | 标尺标注 |
|------|----------|
| 2X | 500 µm |
| 4X | 250 µm |

`长度_µm = 像素距离 × (标尺µm / 标尺像素)`

## 推理顺序（每张图，命中即停）

先检测茎掩膜（Otsu + 最大轮廓），失败则跳过。

```
① YOLO Pose 六点（3–6 共线）
② 相似检索：同倍率 / 同样品 / 缩略图最近邻
      → 借用邻图的内环比例、层分界比例、夹角
③ 纯规则 canonicalize
```

## 规则 canonicalize

```
原图
 → 茎掩膜（Otsu 反阈值 + 闭开运算 + 最大轮廓）
 → 髓心：内环霍夫圆优先，否则距离变换高峰 × 暗度
 → 绿线方向：从髓心估计半径方向，射到树皮 = 点2
 → 层线方向：约偏绿线 40°，夹角夹到 16°–165°
 → 内环半径：夹到 [0.12, 0.32] × 茎半径（2X 先验约 0.21，4X 约 0.24）
 → 点3 = 髓心沿层线走到内环
 → 沿层线做径向灰度剖面，梯度峰切开木质部 / 韧皮部
 → 点6 = 沿层线射到树皮
 → 4–5–6 三倍：若 4→5 < 3×(5→6)，只移点5 到 4→6 的 3/4 处
```

有 YOLO 预测时：髓心在允许范围内向预测靠一点；层上各段半径可按预测比例缩放后融合，仍须满足「两点分开、共线、接到树皮」。

# 第二区域：导管腔 + 局部面积

视图 **4 / 5 / 6**（10X）。在木质部里标出每个导管**腔**，并统计韧皮部 / 髓 / 木质部面积。导管用 **纯 CV**，按腔计数、填腔，不画检测框。染色和曝光差很大；竖向切片裂缝不是导管。

## 三类目标

| 目标 | 画法 | 统计 | 做法 |
|------|------|------|------|
| 导管腔 | 半透明填腔 + 轮廓 | 个数、腔面积之和（µm²） | 亮腔 + 形状/环对比 + 去裂缝 + 拆粘连 |
| 局部木质部 | 橙色虚线外框 = 整图 | 整幅视野面积 | 宽 × 高 |
| 局部韧皮部 / 髓 | 先画组织内缘实线，再在线内叠虚线矩形 | 线内像素面积；没有侧带则为 0 | 列+块分类。左右会换边，不能写死左髓右韧 |

## 标尺

右下角 **100 µm 黑条**（检不到则用 412 px）。右下标尺角（约下 10% × 右 32%）不当导管、不当韧皮部/髓。

```
µm/px = 100 / 黑条像素
面积_µm² = 像素面积 × (µm/px)²
```

## 导管规则

| 量 | 值 |
|----|----|
| 最小等效直径 | **16 µm** |
| 最小腔面积 | **200 µm²**（≈ π×8²） |
| 检测软门槛 | 14 µm / 150 µm²（先多召回，最后再按上表卡） |
| 上限直径 | 约 70 µm |

同时满足才保留：

1. 局部阈值下的**亮腔**（多尺度邻域差，不要全图一张阈值）。过曝大白腔也要留。
2. 圆形度 ≥ 0.45（小腔 <250 µm² 要 ≥ 0.55）；长宽比 ≤ 2.2；凸包填充率 ≥ 0.82。
3. **环对比**：腔比周围壁更亮（Δ≥4）；过曝大腔允许壁也偏白。
4. **壁闭合**：绕腔一圈不能有连续约 90° 的亮缝接到撕裂。
5. **只在木质部**：落在韧皮部/髓掩膜上的丢掉。

不是导管：

- **切片裂缝**：细长白撕口整块挖掉，不要切成一串圆斑。
- **沿裂缝排成一列**的检测（≥4 个、细长排列）整串丢掉；紧挨的 2–4 个真腔保留。
- 右下标尺角、纯白背景。

粘连的 2–4 个腔：距离变换找峰 + **分水岭**拆开，不靠再降面积门槛去拆。个数 = 填腔个数。

## 韧皮部 / 髓

左右哪一侧是韧皮部、哪一侧是髓，因切片方向而变。

```
列分类（左/右是哪类）+ 块分类（空间落点）
 → 用导管前缘把内缘收到木质部交界
 → 先画分界实线，再在线内叠虚线矩形（矩形不越线）
 → 扣掉标尺角和过白区
```

分类器：`models/region2_area_clf.joblib`。侧带宽度约图宽的 1.8%–28%；面积过小则视为没有侧带（面积 0）。

**旧表局部木质部面积 = 整图宽 × 高**，不是扣掉韧皮部/髓之后剩下的组织。新表按客户说明：有韧皮部或髓时改为 `整图 − 韧皮部 − 髓`（图上仍画整图橙框）。

## 流程

```
原图
 → 黑条 100 µm
 → 导管：多尺度亮腔 → 去裂缝 → 分水岭拆粘连
      → 圆度/长宽/环对比/闭壁 → NMS → 面积门槛 → 丢掉裂缝串
 → 韧皮部/髓：分类器分侧带
 → 导管再滤掉落在韧皮部/髓里的
 → 木质部外框 = 整图
 → 画：橙虚线整图 + 侧带实线/虚框 + 填腔 + 左上角统计
 → 个数与面积 → Excel
```

# 第三区域：形成层空心框与连续性评分

视图 **7 / 8 / 9**（20X）。在图中部标出形成层**空心框**（不填色），再按上下衔接好坏打 **1–10 分**。框和分互不改写：调分用 `--score-only`，调框用默认参数或 `--calibrate`。

## 目标

| 项目 | 说明 |
|------|------|
| 输入 | `原图/第三区域/` |
| 输出图 | `自动标定/第三区域/`（洋红空心框 + 分数） |
| 分数 | Excel「形成层连续性评分」三视野 + 汇总平均 |

| 分 | 含义 |
|----|------|
| **1** | 上下衔接的小区域已经出现断层 |
| **5** | 上下衔接的小区域排列散乱，即将断开 |
| **10** | 上下衔接的小区域紧凑衔接 |

画面 hint 按最终 1–10 分档：≤3 低分断层，≤6 散乱将断，≤8 较连续，>8 紧凑衔接。

## 框：先卡中间，再微调

空心矩形，洋红描边，内部不涂色。打分只看框内条带，不改框几何。

1. **水平居中**，宽度约图宽的 88%–95%。
2. **垂直先锁图像中线**（0.50H）；只在中带（约 0.35H–0.65H）找最强水平界面，再按 `0.70×图中心 + 0.30×算法` 轻推。
3. **高度约 1/4 图高**，下限约 0.18H，**上限 1.5 × (H/4) = 0.375H**。

```
原图缩小
 → 竖直中心先行
 → 中带 Sobel 水平梯度，找形成层界面行
 → 合成中心行，按高/宽切矩形
 → 洋红色空心框
```

参数：`models/region3_box_params.json`。`--score-only` 不改框，只用现有参数画框并重打分。

## 评分：CNN 优先，CV 兜底

在已定框上裁条带，分数 round 到 1–10。

```
有 models/yolo/score_regressor.pt  → CNN 回归；CV 特征只写日志
否则 → 框内连续性特征合成 raw，分位映射后 clip 到 1–10
```

| 特征 | 含义 | 与分数 |
|------|------|--------|
| `coverage` | 脊线有信号的列占比 | 越高越好 |
| `gap_ratio` | 空白列占比（断层） | 越高越差 |
| `break_count` | 水平方向断裂段数 | 越多越差 |
| `row_jitter` | 各列灰度峰行号的标准差 | 越大越散乱 |

合成：`2·coverage − 1.5·gap − 0.35·min(断裂,12) − 0.01·min(抖动,60)`。  
无映射时：`4 + 1.8×合成`。权重：`models/region3_score_weights.json`。

## 流程

```
加载框参数；加载 CNN 或 CV 分位

每张原图
 → 中心规则 + 界面微调 → 空心框
 → 框内 CNN 或 CV 打分 1–10
 → 画洋红框 + 分数
 → 视野 7/8/9 → 评分 1/2/3
```

| 相对韧皮部厚度 | 韧皮部长度 / 半径长度 | 无量纲 |
| 相对木质部厚度 | 木质部长度 / 半径长度 | 无量纲 |
| 导管密度 | 导管总数量 / 局部木质部面积 | **vessels·mm⁻²**（面积是 µm²，公式 ×1e6） |
| 平均导管腔面积 | 导管（腔）总面积 / 导管总数量 | µm² / vessel |
| 导管腔面积占木质部比例 | 导管（腔）总面积 / 局部木质部面积 | 无量纲 |

`汇总(均值)` 引用各派生表 / 形成层的 **E 列平均**，不再放原始长度和个数。
